## 📥 Installation

### 1. Download the Extension

You can either download the ZIP file from GitHub or clone the repository using Git.

#### Option A — Clone with Git

```bash
git clone https://github.com/meeer4304/widgetcreator.git
```

#### Option B — Download ZIP

1. Open the GitHub repository.
2. Click the **Code** button.
3. Select **Download ZIP**.
4. Extract the ZIP file to any folder.

---

## 🧩 Install in Your Browser (works for any browser)

### Google Chrome

1. Open **Google Chrome**.
2. Go to:

   ```
   chrome://extensions
   ```
3. Enable **Developer Mode** (top-right corner).
4. Click **Load unpacked**.
5. Select the **MIRA** folder.
6. The extension will now appear in your extensions list.

---

## 🚀 Getting Started

1. Open **[Discord Developer Portal](https://discord.com/developers/applications)** in your browser.
2. Click the **MIRA Widget** in the bottom right.
3. Click **Initialize**.


---


## 🗑 Uninstalling

1. Open your browser's extensions page.
2. Locate **MIRA Widget**.
3. Click **Remove**.
4. Confirm the removal.
